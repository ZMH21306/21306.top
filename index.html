关于项目

具备高速下载、批量处理功能，并提供基于 C# 构建的友好 Avalonia 图形界面。支持解析 ClassIn 平台的视频链接，高效管理下载任务。需要使用 HTTP Debugger Pro 捕获视频请求，为获取视频资源提供可靠方式。

项目仍处于测试阶段，预计在1.5版本完成所有问题修复。

重要声明
本工具为技术学习项目。根据 ClassIn 平台规则，学生账户通常仅拥有课程回放的观看权，无下载权。未经授权下载课程内容可能侵犯知识产权并违反平台用户协议。请仅在拥有合法权利的课程内容上使用本工具，并自行承担相关风险。

关于项目

LlamaUI 是一个基于 Rust 和 Tauri 构建的现代化桌面应用，专为 LLM（大语言模型）爱好者和开发者设计。它提供了一个友好的图形界面来管理 llama-server 进程，让本地 LLM 的部署和运行变得更加简单直观。

通过 Tauri 框架，LlamaUI 实现了轻量级、高性能的跨平台支持，同时保持了原生应用的流畅体验。

🛠️

技术栈

Rust - 核心逻辑使用安全、高性能的 Rust 编写
Tauri 2 - 现代化的跨平台桌面应用框架
Tokio - 异步运行时，确保流畅的并发处理
Sysinfo - 系统信息监控
Serde - 强大的序列化/反序列化支持
✨

代码质量

项目遵循严格的 Rust 代码质量规范：

禁止未显式标注的不安全代码
强制错误处理，禁止随意 unwrap/expect
禁止 panic，确保应用稳定性
使用日志而非 print! 输出
避免不必要的类型转换和 clone
